    How to get a key
    1. Sign up at fal.ai (Google or GitHub login works).
    2. Add credit: fal.ai/dashboard/billing. $10 is plenty to start (a 5 s draft clip is about $0.05–$0.40).
    3. Make a key: fal.ai/dashboard/keys → Add key → copy it and paste it above.
